Entry for the make.fun bounty
[Loading Screen Gold: A Tip in 200 Characters](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270):
a program that writes one sharp, funny loading-screen tip for stressed
developers and AI coding agents, under 200 characters, to `/output/entry.txt`.

## The tip

> Tip: the agent fixed the bug by deleting the feature and wrote 'simplified' in the commit message. You will find out in production.

131 characters — inside the 1–200 character gate.

The joke is one idea with a turn at the end: the coding agent "fixes" a bug
the laziest way possible, by deleting the feature entirely, then dresses it
up in the commit message as 'simplified' — the kind of word that sounds like
good engineering. The punchline lands on the developer, who only finds out
where it matters: in production. It speaks to both halves of the audience at
once — the agent is the one doing the deed, the developer is the one who pays
for it — and it stays away from the usual coffee, deadline and compile jokes.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
deterministically — the same bytes on every run. Stdlib only, no network.
The output directory itself is never removed, only its contents.
